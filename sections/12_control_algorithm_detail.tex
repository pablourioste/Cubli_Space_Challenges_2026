\section{Control Algorithm Detail}
\label{app:control_algorithms}

This appendix holds the implementation detail kept out of
Section~\ref{sec:control_algorithms}: the mode state machine's guard
conditions, the estimator and controller as executable pseudocode, the fixed
gains and tuning parameters, the per-cycle timing budget and the fault
responses. The control law and its rationale --- why an LQR baseline, why a
complementary filter, why the loop runs at \qty{1}{\kilo\hertz} --- stay in
Section~\ref{sec:control_algorithms} and are not repeated here. Anything in
this appendix may change (a re-tuned gain, a revised timing margin) without
the design intent changing; anything in Section~\ref{sec:control_algorithms}
may not.

\subsection{Estimator Pseudocode}
\label{app:estimator_pseudocode}

The block below is the executable form of the complementary filter of
Equations~\eqref{eq:complementary}--\eqref{eq:offset_filter}, run once per
\qty{1}{\milli\second} tick, ahead of the controller step.

\begin{verbatim}
function ESTIMATE(gyro_rate, accel_x, accel_y, dt):
    theta_accel   = atan2(-accel_x, accel_y)
    theta_hat     = (1 - gamma) * (theta_hat_prev + gyro_rate * dt)
                    + gamma * theta_accel
    x_f           = (1 - alpha) * x_f_prev + alpha * theta_hat
    theta_hat_prev = theta_hat
    x_f_prev       = x_f
    return theta_hat - x_f      # offset-corrected tilt fed to the controller
\end{verbatim}

\subsection{Controller Pseudocode}
\label{app:controller_pseudocode}

The block below is the executable form of Section~\ref{sec:pure_lqr_logic},
including saturation and the momentum-desaturation bias omitted from the
high-level listing there.

\begin{verbatim}
function CONTROL_STEP(state_estimate, wheel_speed, mode):
    if mode != EDGE_BALANCE and mode != CORNER_BALANCE:
        return MODE_OPEN_LOOP_COMMAND(mode)

    x_hat = ASSEMBLE_STATE(state_estimate, wheel_speed)   # eq. (x_hat)
    u     = -K_d * x_hat                                  # gain per mode: 3x1 (edge) or 3x9 (corner)

    u = CLAMP(u, -I_CONT_MAX, I_CONT_MAX)                 # driver continuous rating, App. A

    if abs(wheel_speed) > OMEGA_DESAT_THRESHOLD:
        u += DESAT_BIAS(wheel_speed)                      # small bias torque, momentum bleed-off

    return u   # issued as a CAN-FD torque request, one per axis
\end{verbatim}
